# Plain English

Inspired by ASD-STE100 (free standard at asd-ste100.org). This is a short house version, not the standard itself.

## Rules
1. One idea per sentence. Maximum 20 words per sentence in instructions, 25 in descriptions.
2. Active voice: "The script deletes the file", not "The file is deleted".
3. One word = one meaning. Pick a term and keep it (do not switch between "booking", "reservation", "order").
4. Common words before rare ones: "use" not "leverage", "start" not "initiate", "help" not "facilitate".
5. Say the result first, then the reason.
6. No filler: remove "basically", "actually", "in order to", "it is important to note that".
7. Lists for steps. Number steps that must happen in order.
8. Explain a technical term once, in brackets, the first time it appears.

## Check before sending
- Read it as a client whose second language is English. Is any sentence readable two ways? Rewrite it.
